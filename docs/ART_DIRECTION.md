Equoria is a game client delivered through the browser, not a web application with game mechanics.
Bespoke graphical frames, borders, surfaces, ornaments, icons, plaques, and decorative UI assets are intentional product requirements.
Do not replace authored treatments with generic cards, pills, flat borders, Tailwind-style panels, shadcn defaults, Material UI patterns, or SaaS dashboard conventions for maintainability or convenience.
Performance should be solved through appropriate asset formats, reuse, modular construction, lazy loading, and optimization — not by deleting the art direction.
CSS owns responsive layout, typography, data display, states, and interaction. Authored assets own atmosphere, silhouette, prestige, worldbuilding, and ceremonial hierarchy.
When implementation and art direction conflict, preserve the art direction and find a technically sound implementation.
