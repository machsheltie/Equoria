Key judgment calls:

Western Pleasure: Lazy + (low-energy, slow jog/lope is what's judged).
Cutting: Independent + (horse works the cow on a loose rein); Reactive + (instant response to cow movement); Aggressive 0 (cowy intimidation helps, aggression toward people/horses doesn't).
Reining/Dressage/Driving/Fine Harness/Saddleseat: Independent – (anticipating or overriding cues is penalized).
Saddleseat/Fine Harness: Spirited + and Bold + (judged on animation, brilliance, presence); Calm 0 (too quiet reads as flat).
Endurance/Eventing/XC/Steeplechase/Polo/Roping: Independent + (horse must self-rate, read terrain/fences/cattle/ball).
Show Jumping: Nervous 0 (anxious horses are often the most careful about rails).
Racing/Harness/Steeplechase/Polo: Aggressive 0 (competitive drive vs. gate/barn problems roughly cancel).
Harness Racing: Steady + and Playful – (breaking stride is penalized).
Gymkhana: Playful + (game-loving ponies thrive); Calm + (tolerates flags, mounting/dismounting at speed).
Rodeo interpreted as all-around rodeo/ranch performance, not rough stock. If it means bucking stock, Spirited/Aggressive/Stubborn flip toward +.
Nervous and Stubborn are negative nearly everywhere; that's true to life.
